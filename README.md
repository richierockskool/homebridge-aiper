# Homebridge Aiper

Adds support for Aiper pool robots.

## Supported Devices

- Scuba N1 Max and newer models

## Features
Apple Homekit for 

- Smart Mode
- Floor Mode
- Wall Mode
- Waterline Mode
- Battery Status

HomePod Doorbell Chime Support: For louder whole-home alerts, enable Doorbell Chime on your HomePod or HomePod mini. When Aiper sends its HomeKit doorbell notification, selected HomePods can also sound the doorbell chime. Multiple HomePods can be enabled throughout the home. This applies to both Cleaning Complete and May Be Stuck notifications.  

## Installation

npm install -g homebridge-aiper

## Configuration

{
  "platform": "Aiper"
}
